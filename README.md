# Сложно сосредоточиться 

Адаптивный лендинг, свёрстанный по макету в Figma с использованием подхода Mobile-First. Поддерживает светлую и тёмную темы оформления, включая автоматическое переключение в соответствии с системными настройками пользователя.

## Демо
🔗 https://milenaremizova.github.io/slozhno-sosredotochitsya-fd/

## Возможности
- Адаптивная вёрстка для различных размеров экранов.
- Подход Mobile-first.
- Светлая и тёмная темы оформления.
- Автоматическое переключение темы в зависимости от системных настроек пользователя.
- Семантическая разметка HTML.

## Технологии
- HTML
- CSS
- JavaScript

## Что было реализовано
- Перенесён макет из Figma в семантическую разметку HTML.
- Стилизация на CSS с применением Flexbox, Grid, Custom Properties.
- Адаптация под мобильные устройства, планшеты, десктоп.
- Настроено оформление для светлой и тёмной темы, а также возможность темы подстраиваться под системную настройку пользователя.
